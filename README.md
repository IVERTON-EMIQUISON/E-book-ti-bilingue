# 📘 E-book Tecnológico Bilíngue (Libras + Português)

## 🧠 Sobre o Projeto

O **E-book Tecnológico Bilíngue** é um material educacional online que apresenta termos importantes da área de **Tecnologia da Informação** e **Engenharia de Software**, com:

* 📖 Definições simples em português
* ✋ Vídeos em Língua Brasileira de Sinais (Libras)
* 🔊 Leitura em voz dos termos
* 📱 Interface responsiva (celular e desktop)

O objetivo é promover **acessibilidade e inclusão digital**, especialmente para estudantes surdos.

---

## 🚀 Funcionalidades

* 🔍 **Busca em tempo real**
* 🏷️ **Filtro por categorias**
* 📚 **Lista de termos interativos**
* 📄 **Página detalhada de cada termo**
* ✋ **Vídeo em Libras**
* 🔊 **Botão “Ouvir” (Text-to-Speech)**
* 📷 **QR Code para acesso mobile**
* 📱 **Design responsivo**
* ♿ **Configurações de acessibilidade (tamanho de fonte)**

---
